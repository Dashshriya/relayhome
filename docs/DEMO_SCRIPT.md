# RelayHome — 2:45 Demo Plan

Keep the video public, in English, and under 3 minutes. Start with the live product, not slides. Use no copyrighted music or footage.

## 0:00–0:15 — Problem
**Voiceover:** “Family care is made of small actions that can get lost across notes and conversations: confirming an appointment, preparing for it, arranging transport, and checking in. RelayHome turns a request into a plan people can review together.”
**Show:** Dashboard and shared task list.

## 0:15–0:40 — Draft a plan
**Voiceover:** “I’ll enter a fictional request and let RelayHome propose a few clear next steps.”
**Show:** Use the prefilled appointment request and click **Draft a plan**. Wait for the live result.

## 0:40–1:10 — Human approval
**Voiceover:** “The plan is only a draft. Nothing is saved until a person reviews and approves it.”
**Show:** Highlight suggested steps, timing/assignee, and the **Not saved** badge. Click **Approve and save**.

## 1:10–1:35 — Follow-through
**Voiceover:** “Approved tasks are recorded through MCP tools, and the activity trail makes changes visible.”
**Show:** Updated task list/activity trail. Mark a task complete and show the update.

## 1:35–2:10 — Protocol integration
**Voiceover:** “This is a real self-hosted MCP server using Streamable HTTP, not just an MCP mention in the README. The inspector discovers the tools actually advertised by the server.”
**Show:** Scroll to **Live MCP tool discovery**, confirm **Connected**, click **Refresh discovery**, and show live tool names/descriptions. If it says Unavailable, fix the setup before recording.

## 2:10–2:30 — Safety boundary
**Voiceover:** “The demo uses fictional household records. It does not send messages, change real calendars, or give medical advice. A person approves tasks before they are saved.”
**Show:** Privacy/safety copy and activity trail.

## 2:30–2:45 — Close
**Voiceover:** “RelayHome demonstrates a review-first care-coordination workflow with an inspectable MCP integration. The source and setup steps are linked in the repository.”
**Show:** README architecture and run commands.

## Recording checklist
- The MCP panel says **Connected** and shows actual tools.
- No tokens, secrets, or personal household information appear.
- The video depicts actions that really happened during the recording.
- End before 2:50 for margin under the limit.
